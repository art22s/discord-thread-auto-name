# Documentation

**AI Discord Thread Titles** is an OpenClaw companion plugin that creates broad thread titles from conversation history.

| Guide                                 | Covers                                                                                           |
| ------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [Configuration](configuration.md)     | Enable naming, choose a threshold or model, configure account overrides, and resolve bot tokens. |
| [How it works](how-it-works.md)       | Message hooks, conversation history, isolated model calls, rename checks, and state limits.      |
| [Troubleshooting](troubleshooting.md) | Diagnose skipped titles and configuration problems.                                              |
| [Development](development.md)         | Repository layout, local checks, tests, package contents, and releases.                          |

For installation and a quick start, see the [project README](../README.md). For contribution guidelines, see [CONTRIBUTING.md](../CONTRIBUTING.md).
